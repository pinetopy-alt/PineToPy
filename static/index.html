How to write a strategy

A strategy is a Python function signals(df, p). df holds the candles (columns open high low close, indexed by time). p holds your settings. Return a dict of per-bar values:

  • side: +1 buy, -1 sell, 0 nothing, for every bar
  • sl: stop distance in price units (must be above 0 where there is a signal)
  • tp: target distance in price units, or 0 for no fixed target

A signal on a bar means: that bar has CLOSED, enter at the NEXT bar's open. One trade at a time. Profit is measured in R, multiples of the stop distance, after your cost.

Settings: PARAMS = {"length": {"default": 20, "min": 2, "max": 200, "grid": [10, 20, 40]}}. Full validation tries every value in each grid and keeps the one that did best on the in-sample part only.

Optional: MAX_HOLD (bars before a trade is closed at market), WARMUP (bars to skip at the start), valid(p) (return False to skip a combination), plots(df, p) (return a dict of lines to draw on the Visual chart).

Ready to use: np, pd, ema(s, n), sma(s, n), atr(df, n), rsi(s, n), highest(s, n), lowest(s, n), crossover(a, b), crossunder(a, b). print() output appears under your results.

The no-peeking rule: only use data up to each bar. shift(-1), df["close"].max() over the whole series and centered rolling windows all use the future. The tester re-runs your code with later bars hidden and fails the strategy if any signal changes.

Your code runs on your own computer, so only paste code you trust.
