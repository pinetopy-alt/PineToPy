How to write a strategy

A strategy is a Python function signals(df, p). df holds candles (open high low close). p holds settings. Return side (+1 buy, -1 sell, 0 nothing), sl, tp.

Settings: PARAMS = {"length": {"default": 20, "min": 2, "max": 200, "grid": [10, 20, 40]}}

Helpers: np, pd, ema, sma, atr, rsi, highest, lowest, crossover, crossunder

No-peeking: only use data up to each bar. No shift(-1).
